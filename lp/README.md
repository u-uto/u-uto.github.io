# LP 制作・更新ガイド

## フォルダ構成

```
lp/
├── assets/                 ← 全LP共通(原則さわらない)
│   ├── css/lp-base.css     レイアウト・部品のスタイル
│   └── js/lp-base.js       メニュー開閉・スクロール表示・追従ボタン・タブ
├── _templates/basic/       ← 新規LPのひな形
└── beauty/<業態>/
    ├── index.html          文章・構成
    ├── theme.css           色・フォント・角丸
    ├── script.js           そのLPだけの動き(診断・シミュレーター等 / ない場合も)
    └── images/             画像(README.md に一覧と推奨サイズ)
```

## よくある作業

### 文章を変える
`index.html` を開き、`▼ セクション名` のコメントを目印に該当箇所を書き換えます。

### 画像を差し替える
1. `images/README.md` で推奨サイズを確認し、写真を書き出す(JPG / WebP、1枚300KB以下目安)
2. `images/` に置く(例: `hero.jpg`)
3. `index.html` で `images/hero.svg` を検索し、`images/hero.jpg` に書き換え

画像は枠の比率で自動トリミングされます。見せたい位置は `<figure class="c-media" style="--pos:50% 30%">` のように調整できます(横% 縦%)。
枠の比率を変えたいときは `style="--ratio:4/3"` を変更します。

### 色・フォントを変える
`theme.css` の変数を変更します。フォントを変える場合は `index.html` の Google Fonts の `<link>` も合わせて変更してください。

### セクションを増やす・減らす
`▼` コメントから次の `▼` コメントの手前までが1セクションです。丸ごとコピー / 削除できます。
背景色を交互にしたいときは `<section class="l-sec l-sec--alt">` のように `l-sec--alt` を付け外しします。

## 新しいLPを作る

1. `lp/_templates/basic/` を `lp/<ジャンル>/<案件名>/` にフォルダごとコピー
2. `theme.css` で案件の色・フォントを設定
3. `index.html` の【 】部分を書き換え、不要なセクションを削除
4. `images/` を案件の画像に差し替え
5. `<meta name="robots" content="noindex">` を削除
6. ポートフォリオのトップ(`/index.html`)とジャンル一覧(`lp/<ジャンル>/index.html`)にカードを追加
7. `/sitemap.xml` にURLを追加

## 主な部品(class)

| class | 用途 |
| --- | --- |
| `p-hero--full` / `--split` / `--frame` | ヒーロー3種 |
| `c-sec-head` | 英字+日本語のセクション見出し(`--center` で中央寄せ) |
| `c-media` | 画像枠(`--ratio` で比率、`--circle` で円形、`--arch` でアーチ型) |
| `c-row` | 画像と文章の左右交互レイアウト |
| `c-card` / `c-grid--2〜4` | カードとグリッド |
| `c-price` | 料金カード(`is-featured` で強調) |
| `c-table` | 比較表(SPでは横スクロール) |
| `c-voice` | お客様の声 |
| `p-flow__list` | ステップ(`--cols` で列数) |
| `p-faq__item` | よくある質問(開閉式) |
| `c-box` / `c-note` | 注意事項・打消し表示 |
| `c-campaign` | 円形のキャンペーンバッジ |
| `c-sticky` | SPで画面下に追従する申込ボタン |
| `data-reveal` | スクロールでふわっと表示(属性を付けるだけ) |

## 表現の注意(美容・健康ジャンル)

- 「必ず」「絶対」「誰でも」「〇日で〇kg」など、効果を断定・保証する表現は使わない
- お客様の声・事例には「個人の感想・結果であり効果を保証するものではない」旨を添える
- 化粧品は承認された効能の範囲で表現する(「シミが消える」「治る」などは不可)
- 健康食品は医薬品のような効果をうたわない。機能性表示食品は届出の範囲のみ表示する
- 定期購入は、回数・解約条件・支払総額を申込ボタンの近くに明記する
