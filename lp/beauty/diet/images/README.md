# 画像一覧

このフォルダの画像はすべて差し替え用のサンプル(SVGで描いたイメージ)です。

## 差し替え方

1. 写真を用意し、下の表の **推奨サイズ以上** に書き出す(JPG / WebP 推奨、1枚 300KB 以下目安)
2. このフォルダに置く(例: `hero.jpg`)
3. `index.html` 内で `images/hero.svg` を検索し、`images/hero.jpg` に書き換える

画像は枠の比率に合わせて自動でトリミングされます。見せたい位置がずれる場合は、
画像を囲む `<figure class="c-media">` に `style="--pos:50% 30%"`(横% 縦%)を追加して調整してください。
